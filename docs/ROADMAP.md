# Roadmap

## Phase 0 — foundation
- repository conventions, CI, FastAPI, PostGIS, migrations, contracts, tests;
- deterministic astronomy and scoring packages;
- weather-provider interface and Open-Meteo adapter.

## Phase 1 — Armenia recommendation slice
- static candidate generation from DEM, roads, parking, land use, and light pollution;
- local-horizon profiles;
- hourly forecast ingestion;
- recommendation API;
- Flutter home, map/list, place details, route handoff, favorites.

## Phase 2 — closed alpha
- 50–100 manually validated sites;
- 20–50 testers;
- observation feedback and failed-trip tracking;
- confidence calibration and ranking evaluation.

## Phase 3 — paid explorer
- seven-day planning, alerts, offline region, multiple profiles, subscription;
- commercial provider licensing and production observability.

## Phase 4 — expansion
- community media and rights pipeline;
- observatories, museums, and equipment discovery;
- AI tool gateway;
- additional countries and partner integrations.
