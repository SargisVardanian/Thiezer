# Thiezer product brief

Thiezer is an astronomy travel platform. Its core unit is a reproducible observation experience:

`place + real photo + celestial object + time + equipment + forecast + actual conditions + route + user impression`

## First product promise

For a user location, observation target, mode, and time range, Thiezer returns a small set of reachable places with:

- valid observation windows;
- an explainable task-specific score;
- forecast confidence and explicit warnings;
- honest naked-eye/camera/telescope expectations;
- an external route handoff.

## MVP

1. Visual home screen with a licensed real night-sky image.
2. “Find this sky” for Milky Way, Moon, and bright planets.
3. Dynamic map with seven useful forecast days and days 8–14 marked as trend only.
4. Naked-eye, binocular, and wide-angle-camera modes.
5. Ranked places, hourly conditions, explanations, favorites, and route handoff.
6. Armenia-first validated dataset.

## Deferred

Community uploads, observatory booking, museums, stores, rentals, subscriptions, embedded navigation, aurora, deep-sky planning, video, and Thiezer AI are deferred until recommendation accuracy is validated.
