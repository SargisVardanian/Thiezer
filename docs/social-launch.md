# Thiezer Armenia Social Launch

## Brand position

Thiezer Armenia should read as a modern Armenia-focused news brand:

- Armenian first for editorial framing.
- Russian for regional accessibility.
- English for diaspora and international reach.

## Channels

### Telegram

- Purpose: urgent updates, direct links to full site stories, rapid reaction.
- Format mix: headline + one-paragraph summary + site link.
- Launch need: create channel, reserve `@thiezer` or closest available handle, upload avatar and description.

### Facebook

- Purpose: longer context posts and diaspora distribution.
- Format mix: daily recap post, featured discussion thread, boosted top story when budget exists.
- Launch need: create Page, add cover image, define category and contact email.

### Instagram

- Purpose: visual explainers, reels, quote cards, and story roundups.
- Format mix: 4:5 carousel for top story, story summary, short reel with subtitles.
- Launch need: create professional account, connect with Meta Business Suite, prepare visual template kit.

## Daily posting baseline

- Morning: one breaking or agenda-setting update.
- Midday: one explainer or context post.
- Evening: one daily recap post.

## Naming

- Public name: `Thiezer Armenia`
- Bio concept: `Daily news from Armenia in Armenian, Russian, and English.`

## Dependencies outside code

- Account credentials.
- Logo/avatar.
- Cover/banner images.
- Final outbound links and analytics setup.
